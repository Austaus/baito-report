# Arubaito Report Generator

Static web app for generating an editable monthly arubaito work report and official PDF preview.

## Files

- `index.html` - app markup
- `style.css` - dashboard and preview styling
- `script.js` - shift generation, salary-limit handling, PDF generation, and saved defaults

## Run Locally

Open `index.html` directly in a browser, or serve this folder with any static file server.
